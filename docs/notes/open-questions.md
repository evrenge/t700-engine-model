Anything the report does not answer goes here rather than into the code as a guess.
Each entry: what is missing, where it is needed, where it was looked for, and what
blocking it costs.

**Each row states what was asked and what was decided, and nothing more.** The
investigations behind the closed ones ran to 126 KB inside these table cells -- #47 alone
was 32 KB -- and were cut on 2026-09-14, once the project was finished, on the principle
that this file should carry the decision rather than the route to it. Every word of that
history is in git history; `git log -p docs/notes/open-questions.md` is the record.
`tests/test_open_questions_ledger.py` fails if a closed row states a verdict without a
finding, which is what eleven of them did before the cut.
